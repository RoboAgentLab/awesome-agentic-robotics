## [Flora: An Open Model Suite for Scaling Robotics Data Engines](https://research.nvidia.com/labs/gear/flora/)

Temporal segmentation, action captions, and process/outcome rewards for human and robot manipulation videos. These models provide data and feedback components for robotics learning workflows.
